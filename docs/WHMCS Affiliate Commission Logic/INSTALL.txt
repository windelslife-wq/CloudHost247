1. SYSTEM REQUIREMENTS
================================================================================

Minimum Requirements:
- WHMCS 8.0 or higher
- PHP 7.4 or higher (PHP 8.x recommended)
- MySQL 5.7+ or MariaDB 10.3+
- WHMCS Affiliate System enabled (Setup > General Settings > Affiliates)

Recommended:
- WHMCS 8.5+
- PHP 8.1+
- MySQL 8.0+

Note: Make sure the "Affiliates" feature is enabled in your WHMCS installation
before using this module.


================================================================================
2. FILE UPLOAD
================================================================================

Step 2.1: Extract the module package on your local computer.

You should see a folder named "customaffiliate" containing:
- customaffiliate.php      (main module file)
- hooks.php                (hook registrations)
- lib/
  - CommissionManager.php  (core logic)
  - UpgradeHandler.php     (upgrade/downgrade handler)
- utilities.php            (maintenance script)
- schema.sql               (database schema)
- README.md                (documentation)

Step 2.2: Upload the folder to your WHMCS server.

Using FTP/SFTP or your hosting control panel file manager:
- Upload the entire "customaffiliate" folder to:
  /modules/addons/customaffiliate/

The path should look like this on your server:
  /home/username/public_html/modules/addons/customaffiliate/
  or
  /var/www/html/modules/addons/customaffiliate/

Step 2.3: Set correct file permissions.

Via SSH (recommended):
  cd /path/to/whmcs/modules/addons/
  chmod -R 755 customaffiliate/
  chown -R www-data:www-data customaffiliate/   (adjust user/group as needed)

Or via FTP:
- Set folder permissions to 755
- Set file permissions to 644

3. DATABASE SETUP
================================================================================

The module will attempt to create required tables automatically when activated,
but running the schema manually first is recommended for production environments.

Option A: Using phpMyAdmin
---------------------------
1. Log in to phpMyAdmin
2. Select your WHMCS database
3. Click the "SQL" tab
4. Open the schema.sql file from the module folder
5. Copy and paste the contents into the SQL box
6. Click "Go" to execute

Option B: Using MySQL CLI
--------------------------
1. SSH into your server
2. Run the following command:

   mysql -u YOUR_DB_USERNAME -p YOUR_WHMCS_DATABASE < /path/to/whmcs/modules/addons/customaffiliate/schema.sql

3. Enter your MySQL password when prompted
4. You should see no errors (blank output means success)

Option C: Auto-Creation (Easiest for Testing)
---------------------------------------------
- Skip this step entirely.
- The module activation process will create tables automatically.
- Note: If auto-creation fails due to permissions, run schema.sql manually.

4. MODULE ACTIVATION
================================================================================

Step 4.1: Log in to WHMCS Admin Panel

Step 4.2: Navigate to Addon Modules
- Go to: System Settings > Addon Modules
  (or in older WHMCS: Setup > Addon Modules)

Step 4.3: Find and Activate
- Locate "Custom Affiliate Commission" in the module list
- Click the "Activate" button next to it
- If activation succeeds, you'll see a green success message

Step 4.4: Configure Access Permissions (Important!)
- After activation, you may see a section for "Access Control"
- Select the admin roles that should be able to access this module
- At minimum, select "Full Administrator"
- Click "Save Changes"


================================================================================
5. CONFIGURATION
================================================================================

Step 5.1: Open Module Settings
- In the Addon Modules list, find "Custom Affiliate Commission"
- Click "Configure" (or the gear icon)

Step 5.2: Set Product Group
- Field: "Web Hosting Product Group"
- Action: Select your Web Hosting product group from the dropdown
- Note: This dropdown auto-populates from your existing product groups.
  If it's empty, create a product group first in Products/Services.

How to find your product group ID if unsure:
- Go to: Configuration > System Settings > Products/Services > Product Groups
- Look for your "Web Hosting" or "Shared Hosting" group
- The module dropdown will show names with IDs

Step 5.3: Set Commission Percentages
- "First Commission Percentage": Enter 50 (for 50%)
- "Recurring Commission Percentage": Enter 20 (for 20%)
- These are the defaults and can be adjusted to your business needs

Step 5.4: Enable Debug Logging
- Check "Enable Debug Logging" during initial setup and testing
- This writes detailed logs to: Utilities > Logs > Activity Log
- You can disable this after everything is working correctly

Step 5.5: Save Configuration
- Click "Save Changes"
- You should see a success message

6. TESTING
================================================================================

Test 1: Verify Module Dashboard
-------------------------------
1. Go to: Addons > Custom Affiliate Commission
2. You should see the dashboard with:
   - Statistics cards (all showing 0 for now)
   - Recent Activity table (empty)
   - Configuration Summary showing your selected product group
3. If the dashboard loads without errors, the module is working

Test 2: Create a Test Affiliate
-------------------------------
1. Go to: Operations > Affiliates
2. Create or note an existing affiliate account
3. Copy the affiliate referral link

Test 3: Simulate a New Customer Purchase
----------------------------------------
1. Use a different browser or incognito window
2. Visit the affiliate referral link
3. Register as a NEW client (must be a new client to trigger first commission)
4. Purchase a product from your configured Web Hosting group
5. Pay the invoice (use a test payment gateway or mark as paid in admin)
6. Check: Addons > Custom Affiliate Commission > Recent Activity
   - You should see a "first_commission" entry
7. Check: Operations > Affiliates > View Affiliate
   - The commission should appear in the affiliate's history

Test 4: Simulate a Recurring Payment
------------------------------------
1. Wait for the hosting service to renew (or manually create a renewal invoice)
2. Mark the renewal invoice as Paid
3. Check the module dashboard
   - You should see a "recurring_commission" entry at 20%
4. Check the affiliate account
   - The commission should be 20% of the renewal amount

Test 5: Verify Non-Hosting Products Are Excluded
--------------------------------------------------
1. Use the affiliate link again (or a different new client)
2. Purchase a domain name or any product NOT in the Web Hosting group
3. Pay the invoice
4. Check: Operations > Affiliates > View Affiliate
   - There should be NO commission for this product
5. Check module logs: Utilities > Logs > Activity Log
   - Look for "[CustomAffiliate] Product not in configured group - skipping"

Test 6: Test Refund Handling
----------------------------
1. Find the test invoice from Test 3
2. Go to: Invoices > View Invoice > Refund
3. Issue a full refund
4. Check module dashboard
   - A "refund" action should appear in the log
5. The first commission flag is now reset - if the client pays again,
   it will be treated as a first payment (50%)

7. TROUBLESHOOTING
================================================================================

Issue: "Module activation failed"
---------------------------------
- Check that the files are uploaded to the correct path
- Verify PHP version is 7.4 or higher
- Check file permissions (755 for folder, 644 for files)
- Look for errors in WHMCS System Activity Log

Issue: "Tables already exist" error
-----------------------------------
- This happens if the tables were created manually and then auto-creation runs
- Safe to ignore - existing tables will be used
- If you need fresh tables, run: DROP TABLE mod_customaffiliate_commissions;
  and DROP TABLE mod_customaffiliate_log; then reactivate

Issue: "No product groups in dropdown"
---------------------------------------
- Go to: Configuration > System Settings > Products/Services > Product Groups
- Create a product group first, then return to module settings
- The dropdown updates automatically

Issue: "Commissions not being calculated"
-----------------------------------------
1. Check Utilities > Logs > Activity Log for "[CustomAffiliate]" entries
2. Verify the product is in the configured group
3. Verify the client has an affiliate ID assigned (tblclients.affiliateid)
4. Ensure the invoice status is "Paid" (not "Payment Pending")
5. Check if duplicate prevention blocked the commission (check mod_customaffiliate_log)

Issue: "Default WHMCS commission still applies to non-hosting products"
----------------------------------------------------------------------
- This can happen if the AffiliateCommission hook conflicts with another module
- Try disabling other affiliate-related modules temporarily
- The hook priority is set to 1 (highest), but some configurations may override it
- As a workaround, set default affiliate commission in WHMCS to 0% and let this module handle all calculations

Issue: "Cron job not processing commissions"
--------------------------------------------
- The module is compatible with cron jobs automatically
- Verify the WHMCS cron is running: Utilities > Automation Status
- Check Activity Log for "[CustomAffiliate]" entries from cron-executed payments
- Ensure the module folder is readable by the cron user

Issue: "Commission percentage is wrong"
--------------------------------------
- Check the module settings for correct first/recurring values
- Check mod_customaffiliate_commissions table for first_commission_paid flag
- A refunded invoice resets the flag - next payment will be treated as first payment again
- If you need to manually fix a service, use the utility script:
  php /path/to/whmcs/modules/addons/customaffiliate/utilities.php reset --service_id=123

8. CRON JOB SETUP (OPTIONAL)
================================================================================

For additional maintenance, you can set up a cron job to audit commission records:

Edit your crontab:
  crontab -e

Add one of these lines:

# Daily audit at 3:00 AM
0 3 * * * cd /path/to/whmcs && php modules/addons/customaffiliate/utilities.php audit >> /var/log/whmcs_affiliate_audit.log 2>&1

# Weekly commission report every Monday at 8:00 AM
0 8 * * 1 cd /path/to/whmcs && php modules/addons/customaffiliate/utilities.php report --start_date=$(date -d '7 days ago' +\%Y-\%m-\%d) --end_date=$(date +\%Y-\%m-\%d) >> /var/log/whmcs_affiliate_report.log 2>&1

Note: Make sure the cron user has permission to execute PHP and access WHMCS files.

10. SUPPORT & UPDATES
================================================================================

For issues related to this module:
1. Check the Activity Log for [CustomAffiliate] debug messages
2. Review the README.md file included in the module folder
3. Verify your WHMCS version meets the minimum requirements
4. Check for conflicts with other affiliate or commission-related modules

To update the module:
1. Backup your database tables: mod_customaffiliate_commissions and mod_customaffiliate_log
2. Replace the module files with the new version
3. Check if any database migrations are needed (see release notes)
4. Test in a staging environment before applying to production
