Build a complete WHMCS addon module (WHMCS 8.9, PHP 7.4, IonCube 10/11) named "hostx_tools" for HostX v2.2.6.

CORE REQUIREMENTS:

1. API + FALLBACK SYSTEM

- Use API for:
  - Domain WHOIS
  - IP WHOIS
  - Domain Availability

- Add fallback:
  - Local WHOIS via port 43 (PHP WHOIS library)

- Must:
  - Never break page if API fails
  - Handle timeout/errors safely
  - Return structured output (JSON → formatted UI)

2. APIs TO USE

- WHOIS:
  - Primary: WhatIsMyIP API
  - Fallback: PHP WHOIS (port 43)

- IP Tools:
  - Primary: IPinfo Lite
  - Fallback: IPWho API

- DNS Tools:
  - Use native PHP: dns_get_record()

3. CACHING SYSTEM

- Cache all results (DNS, WHOIS, IP) for 10 minutes
- Use WHMCS database (Capsule) or file cache
- Prevent duplicate API calls

4. ERROR HANDLING (VERY IMPORTANT)

- If API fails:
  - Automatically switch to fallback
- If fallback fails:
  - Show user-friendly error message
- NEVER show PHP warnings or blank page

5. SECURITY

- Sanitize all inputs
- Escape all outputs
- CSRF protection for forms
- Rate limit API-heavy tools

6. PERFORMANCE

- Use AJAX for all tool requests
- Lazy load results
- Timeout control (max 5–10 sec per request)

7. OUTPUT FORMAT

Domain WHOIS must return:
- Registrar
- Creation Date
- Expiry Date
- Name Servers
- Status
- Raw WHOIS

IP WHOIS must return:
- IP Address
- ISP / Organization
- Country / City
- ASN

Domain Availability:
- Available / Taken
- Registrar (if available)

8. COMPATIBILITY

- Fully compatible with WHMCS 8.9
- Must work with HostX theme
- No layout breaking
- No fatal errors on module activation

9. STRUCTURE

/modules/addons/hostx_tools/
- hostx_tools.php
- hooks.php
- /templates/
- /includes/
- /api/
- /cache/

10. FINAL RESULT

- Fully working module
- No missing files
- No placeholder logic
- Ready to upload and activate
